Privacy Policy

MDC Bot and MDC VERIFY. Last updated October 4, 2026.

MDC Bot is a Discord bot for server verification, Roblox username linking, and moderation. MDC VERIFY is the website that generates verification codes.

Data we use

The bot stores Discord user IDs, verification status, linked Roblox usernames, and moderation warnings in memory while it is running. This data is lost when the bot restarts. The website stores a local browser lock so a code is not generated again for 24 hours. That lock stays on your device.

What we do not do

We do not sell personal data. We do not ask for your Discord password. Verification codes are single-use. Roblox usernames are checked against Roblox's public username API.

Messages

After verification, the bot may send one thank-you direct message. That message can be closed with the button or is removed after 15 minutes.

Contact

Questions about this policy can be sent to the server owner in the official MDC Discord server.
